ZAPBOX⚡️WEB INSTALLER (Touch 3.5")

Use with JC3248W535C (ESP32-S3, 3.5" QSPI touch display, 480×320). T-Display-S3 installer see here  |  Headless installer see here.

1- Flash firmware

  • Connect your ZapBox Touch 3.5" to USB (the ESP32-S3 USB port)
  • Leave the latest firmware version selected
  • Press 🔥 Flash - connect and follow screen instructions
Your browser does not support installing things on ESP devices. Use Google Chrome or Microsoft Edge. Ah snap, you are not allowed to use this on HTTP!

Note: The configuration data can be deleted using "Erase device." Otherwise, it will be retained even with the new firmware.

Note on the Touch 3.5" version: This firmware runs on the JC3248W535C module — ESP32-S3-WROOM-1 with 3.5" IPS 480×320 QSPI display and capacitive multi-touch. The display replaces LEDs for all status feedback. Serial logs are still available for diagnostics.

2- Prepare connection

When you flash a new ESP32-S3 or use "Erase device." the ZapBox automatically starts in configuration mode. The display shows "CONF / SERIAL CONFIG MODE".

→ The ZapBox is now ready to receive configuration data. ⚙️

If parameters have already been saved and need to be changed, you can also open CONF mode retrospectively by tapping the touch screen and holding for at least 5 seconds, or by pressing the BOOT button.

Note: The connection will remain active for 3 minutes (180 seconds) before it is automatically disconnected. If data is already available, you can terminate the connection prematurely by tapping the screen again.

3- Load config values

  • Press 🔌 Connect - select the connection and connect.
  • Set or check whether the ZapBox is in configuration mode.⚙️✅
  • If values are already available, press 📖 Read Config.
  • Define your configuration.📝 At least Wi-Fi and device data.
  • Press 🔥 Write Config to write the configuration.
  • Press 🔄 Restart to restart while staying connected.
  • Press 🔌 Disconnect or refresh website to close connection.

Multi-Channel Mode

The ZapBox Touch 3.5" supports up to 6 independent relay channels. Each channel maps to a GPIO output that can switch a relay, solenoid, or any other 3.3 V-driven load.

Available GPIO channels:

CH01GPIO 5(default)
CH02GPIO 6
CH03GPIO 7
CH04GPIO 9
CH05GPIO 14
CH06GPIO 15

Each channel is configured independently in your LNbits extension (zapbox / bitcoinswitch) — each switch gets its own QR code and amount. The device activates exactly the GPIO returned in the "paid" event.

Reserved GPIOs (not available as relay channels):
GPIO 17 / GPIO 18 — I²C bus (touch controller AXS15231B + NFC reader PN532, always active)
GPIO 16 — touch interrupt (INT line of AXS15231B, shared with NFC IRQ)
GPIO 46 — strapping pin reserve (do not connect external load)
GPIO 21 — display backlight PWM (managed by firmware)

leave empty for normal mode (default)

5 (default CH01)

Note: As soon as something is entered in the "Wallet Invoice/Read Key" field, "THRESHOLD MODE" becomes active. "NORMAL MODE" then no longer works.

NFC Bolt Cards work reliably and securely with all major Lightning wallets and PoS systems. This is the recommended default.

The PN532 NFC reader shares the I²C bus (GPIO 17/18) with the touch controller. The ZapBox automatically detects the PN532 at address 0x24 on startup — no additional wiring is required beyond connecting the module to the same I²C pins.

The NFC Bolt Card functionality requires the LNbits extension "zapbox_extension". Extension manifest source:
https://installer.zapbox.space/extensions.json

PN532 (I²C 0x24) — Active NFC reader connected to the shared I²C bus on GPIO 17 (SCL) and GPIO 18 (SDA). Supports pre-programmed Bolt Cards for contactless Lightning payment. Also reads passive NTAG 213/215/216 tags for LNURL-based payment. Auto-detected at startup — no configuration needed.

Common Wallet Errors

"bitcoinswitch ... is disabled" → The Bitcoin Switch extension was actively disabled in LNbits.

"No active bitcoinswitch connections" → WebSocket handshake between wallet and ZapBox failed. Wait or restart the ZapBox.

NFC Extension Mismatch

If the serial log shows:

[WARN][NFC] Bolt Card tap detected – NFC is not supported by the active extension (bitcoinswitch).
[WARN][NFC] To use NFC / Bolt Cards, switch to zapbox_extension (apiPath = "zapbox").

→ Create a device in the zapbox_extension and use its device string.

Troubleshoot

Connection problems

  • Check that the USB cable is plugged directly into the USB port of the ESP32-S3 module.
  • Use a data-capable USB cable (not a charge-only cable).
  • If you see "No port selected": check/install the USB-serial drivers for your OS.
  • Double connection: check whether a connection already exists in another browser tab.
  • A page refresh with CTRL+F5 can also help.
  • Message "Installation failed ⚠️ Your ESP32 board is not supported" → You are using the wrong firmware variant. Use this Touch 3.5" installer for JC3248W535C boards only.
  • If nothing else helps, erase the device via https://espressif.github.io/esptool-js/ and reflash.

Boot into flash mode (if flash fails)

  • Connect the board via USB
  • Press and hold the BOOT button
  • While still pressing BOOT, press RESET (or disconnect/reconnect power)
  • Release RESET, then release BOOT
  • Retry step 1
